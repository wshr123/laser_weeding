## 1. XY位置命令接口

### Arduino端 (`control_tennsy.ino`)
**支持的命令格式：**
- `XY:x,y` - 移动当前活动振镜
- `XY1:x,y` - 移动振镜1
- `XY2:x,y` - 移动振镜2
- `XYS:x,y` - 有符号格式移动当前活动振镜
- `XYS1:x,y` - 有符号格式移动振镜1
- `XYS2:x,y` - 有符号格式移动振镜2

**坐标轴处理：**
```cpp
// 第389-390行：XY命令解析
long yVal = xStr.toInt();  // ⚠️ 注意：x和y被对调了
long xVal = yStr.toInt();
```
**注释说明：** "注意：XY传输中需要对调XY轴"

### 上位机端 (`send_to_teensy.py`)
**使用的命令格式：**
```python
# 第201-202行
prefix = f"XY{galvo_index + 1}"
command = f"{prefix}:{x},{y}"
```
**示例：** `XY1:100,200` 或 `XY2:100,200`

### ✅ 接口匹配情况
- **命令格式：** ✅ 匹配
- **振镜索引：** ✅ 匹配（Python: 0-based → Arduino: 1-based转换正确）
- **坐标轴对调：** ⚠️ **需要确认**
  - Arduino代码明确对调了x和y
  - 如果这是设计需求（硬件特性），则正确

## 2. LASER激光控制接口

### Arduino端 (`control_tennsy.ino`)
**支持的命令格式：**
- `LASER:ON` / `LASER:OFF` - 控制当前活动振镜的激光
- `LASER1:ON` / `LASER1:OFF` - 控制振镜1的激光
- `LASER2:ON` / `LASER2:OFF` - 控制振镜2的激光
- `LASER:1` / `LASER:0` - 数字格式（ON/OFF）

**解析逻辑：** (第409-443行)
- 如果命令包含数字（如`LASER1:`），则解析为指定振镜
- 否则使用当前活动振镜

### 上位机端 (`main.py`)
**使用的命令格式：**
```python
# 第1210行：先选择振镜
if self.galvo_controller.select_galvo(galvo_idx):
    # 第1226行：然后发送激光命令
    self.galvo_controller.send_command("LASER:ON")
    # 或
    self.galvo_controller.send_command("LASER:OFF")
```

### ⚠️ 接口匹配情况
- **功能：** ✅ 可以工作
- **效率：** ⚠️ **可以优化**
  - 当前方式：需要两次命令（`GALVO:n` + `LASER:ON`）
  - 优化方式：直接使用 `LASER1:ON` / `LASER2:ON`，只需一次命令
  - **建议：** 修改为直接使用 `LASER{galvo_index+1}:ON/OFF` 格式

## 6. 发现的问题和建议

### ⚠️ 问题1：坐标轴对调
**位置：** `control_tennsy.ino` 第389-390行

**问题描述：**
Arduino代码在解析XY命令时对调了x和y坐标：
```cpp
long yVal = xStr.toInt();  // xStr的值赋给了yVal
long xVal = yStr.toInt();  // yStr的值赋给了xVal
```

**注释说明：** "注意：XY传输中需要对调XY轴"

**建议：**
1. 如果这是硬件特性（振镜物理安装方向），则保持现状
2. 如果不是，需要修正为：
   ```cpp
   long xVal = xStr.toInt();
   long yVal = yStr.toInt();
   ```
3. **需要与硬件团队确认**：这是设计需求还是bug

---

### ⚠️ 问题2：LASER命令效率
**位置：** `scripts/main.py` 第1210-1230行

**问题描述：**
当前使用两步操作控制激光：
1. 先调用 `select_galvo(galvo_idx)`
2. 再发送 `LASER:ON/OFF`

**建议：**
直接使用 `LASER{galvo_index+1}:ON/OFF` 格式，减少一次命令传输：
```python
# 当前方式（2次命令）
self.galvo_controller.select_galvo(galvo_idx)
self.galvo_controller.send_command("LASER:ON")

# 优化方式（1次命令）
self.galvo_controller.send_command(f"LASER{galvo_idx + 1}:ON")
```

**优势：**
- 减少通信延迟
- 减少命令解析开销
- 代码更简洁

---

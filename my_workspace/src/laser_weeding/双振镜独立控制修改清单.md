# 双振镜独立控制修改清单

## 修改目标
将当前的全局单一状态机改为每个振镜独立的状态机，使得两个激光可以同时打开照射。

## 修改步骤（按顺序进行，每步修改后测试）

### 步骤1：初始化数据结构改造
**位置**：`__init__` 方法中的状态变量初始化部分（约158-182行）
**改动**：
- 将 `self.system_state` → `self.galvo_states`（列表）
- 将 `self.current_target` → `self.galvo_current_targets`（列表）
- 将 `self.laser_on` → `self.galvo_laser_on`（列表）
- 将 `self.state_start_time` → `self.galvo_state_start_times`（列表）
- 将 `self.position_history` → `self.galvo_position_histories`（列表）
- 保留 `self.active_galvo_index`（用于兼容，后续可移除）
- 添加 `self.galvo_target_queues`（每个振镜的目标队列）

### 步骤2：修改 set_laser 方法
**位置**：`set_laser` 方法（约795-812行）
**改动**：
- 重命名为 `set_galvo_laser(self, galvo_idx, enable)`
- 使用 `self.galvo_laser_on[galvo_idx]` 替代 `self.laser_on`
- 调用时传入 `galvo_idx` 参数

### 步骤3：修改 change_state 方法
**位置**：`change_state` 方法（约779-793行）
**改动**：
- 重命名为 `change_galvo_state(self, galvo_idx, new_state)`
- 使用 `self.galvo_states[galvo_idx]` 替代 `self.system_state`
- 使用 `self.galvo_state_start_times[galvo_idx]` 替代 `self.state_start_time`
- 调用 `set_galvo_laser` 替代 `set_laser`

### 步骤4：修改 galvo_control_loop
**位置**：`galvo_control_loop` 方法（约739-777行）
**改动**：
- 将第768行的 `self.laser_on and idx == self.active_galvo_index` 
  改为 `self.galvo_laser_on[idx]`

### 步骤5：重构 control_loop 主逻辑
**位置**：`control_loop` 方法（约310-419行）
**改动**：
- 将当前的状态机逻辑改为循环处理每个振镜
- 调用新的 `_process_galvo_state_machine` 方法

### 步骤6：添加 _process_galvo_state_machine 方法
**位置**：在 `control_loop` 方法之后添加新方法
**改动**：
- 实现每个振镜独立的状态机逻辑
- 处理 IDLE/TRACKING/FIRING 三个状态

### 步骤7：修改目标分配逻辑
**位置**：`update_targets` 和相关方法
**改动**：
- 修改目标分配，支持每个振镜独立队列
- 添加 `_select_target_for_galvo` 方法

### 步骤8：修改可视化 draw_info
**位置**：`draw_info` 方法（约814-949行）
**改动**：
- 使用 `self.galvo_states` 和 `self.galvo_laser_on` 列表
- 显示每个振镜的状态

### 步骤9：修改状态发布 publish_status
**位置**：`publish_status` 方法（约951-1010行）
**改动**：
- 发布每个振镜的状态信息
- 使用新的状态列表

## 注意事项
1. 每一步修改后都要测试，确保代码可以运行
2. 保持向后兼容，如果某个地方还在使用旧变量，先保留
3. 修改要简洁，只改必要的地方
4. 测试时要检查两个振镜是否能独立工作

## 功能概述

本程序用于手动标定相机与振镜系统之间的三维坐标变换关系。支持：

- **黑色圆圈检测**：自动检测标定板上的黑色圆形标记
- **多批次标定**：支持将标定板放在不同位置进行多次标定
- **手动微调**：使用键盘精确调整激光对准位置
- **深度信息**：使用深度相机信息进行3D坐标计算
- **实时显示**：实时显示检测结果和标定状态

**最终输出**：相机坐标系到振镜坐标系的刚体变换矩阵（旋转矩阵R和平移向量t）

## 准备工作

### 1. 硬件准备
- ✅ Intel RealSense 深度相机（已连接并可用）
- ✅ 振镜系统（XY2-100协议，已连接串口）
- ✅ 黑色圆形标定板（至少包含2个黑色圆圈，建议更多）
- ✅ 确保串口设备路径正确（默认：`/dev/ttyACM0`）

### 2. 软件准备
- ✅ ROS环境已配置
- ✅ 相机驱动已安装（`realsense2_camera`）
- ✅ 标定程序包已编译
- ✅ 配置文件路径正确（`cam_params.yaml`）

### 3. 标定板准备
- **圆圈数量**：每个批次至少需要检测到2个黑色圆圈（建议3个以上）
- **圆圈大小**：半径在10-150像素范围内
- **颜色要求**：纯黑色或接近黑色
- **形状要求**：尽量接近圆形（圆度≥0.6）
- **布局建议**：圆圈间距≥35像素，避免重叠

### 4. 检测方法选择（可选）

程序支持两种黑色圆圈检测方法，可在代码中手动选择：

- **`adaptive_threshold`**（默认）：自适应阈值方法
  - ✅ 优点：抗反光能力强，对光照变化鲁棒
  - ✅ 适用场景：有反光、光照变化大的环境
  - ✅ 特点：使用灰度图+自适应阈值，基于凸包计算

- **`hsv`**：HSV颜色空间方法
  - ✅ 优点：简单直接，对纯黑色效果好
  - ✅ 适用场景：标准光照条件，无反光
  - ✅ 特点：使用HSV颜色空间，V<80, S<100

**修改方法**：编辑 `scripts/galvo_calibrator_depth.py` 文件，在第162行左右找到：
```python
self.detection_method = 'adaptive_threshold'  # 可选: 'hsv' 或 'adaptive_threshold'
```
修改为：
```python
self.detection_method = 'hsv'  # 可选: 'hsv' 或 'adaptive_threshold'
```

## 启动程序

### 方式一：使用Launch文件（推荐）

```bash
cd ~/my_workspace
source devel/setup.bash
roslaunch laser_weeding calibration.launch
```

### 方式二：手动启动节点

```bash
# 终端1：启动相机
roslaunch realsense2_camera rs_camera.launch align_depth:=true

# 终端2：启动标定节点
rosrun laser_weeding galvo_calibrator_depth.py \
    _serial_port:=/dev/ttyACM0 \
    _serial_baudrate:=115200 \
    _transform_config_file:=cam_params.yaml \
    _galvo_index:=0
```

### 启动后检查
- ✅ 查看终端输出，确认"Manual Galvo Calibration Node initialized successfully!"
- ✅ 查看检测方法日志：`Black circle detection method: adaptive_threshold`（或 `hsv`）
- ✅ 确认相机图像正常显示（可通过 `rqt_image_view /manual_calibration_image` 查看）
- ✅ 确认检测到黑色圆圈（图像中应显示绿色圆圈标记）

## 标定流程

### 整体流程概述

```
准备标定板
    ↓
第1批次：放置位置1 → 按B开始 → 逐个标定圆圈 → 按M完成批次
    ↓
第2批次：移动标定板到位置2 → 按B开始 → 逐个标定 → 按M完成
    ↓
第3批次：移动标定板到位置3 → 按B开始 → 逐个标定 → 按M完成
    ↓
...
    ↓
按C保存：使用所有批次数据计算变换 → 保存结果
```

### 详细操作步骤

#### **第1批次标定**

1. **放置标定板**
   - 将标定板放置在相机视野内（建议在视野的某个区域，如左上角）
   - 确保标定板上的黑色圆圈清晰可见
   - 确保深度信息有效（避免过近或过远）

2. **开始标定**
   - 按键盘 **`B`** 开始第一批次标定
   - 程序会自动检测黑色圆圈（至少需要2个）
   - 终端会显示：`开始第 1 批次标定`，`检测到 N 个黑色圆圈`

3. **标定第一个圆圈**
   - 程序会自动对准第一个圆圈（显示红色标记）
   - 如果自动对准不够精确，使用 **`WASD`** 键手动微调激光位置
   - 调整到满意的位置后，按 **`R`** 记录该点
   - 终端显示：`成功记录第 1 个标定点`

4. **标定后续圆圈**
   - 程序自动进入下一个圆圈（显示红色标记）
   - 重复步骤3的操作：微调 → 按R记录
   - 可以使用 **`N`**（下一个）或 **`P`**（上一个）切换目标

5. **完成当前批次**
   - 标定完当前位置的所有圆圈后，按 **`M`** 完成当前批次
   - 终端显示：`批次 1 已完成！`，`本批次标定点数: N`
   - 提示：`请移动标定板到新位置，然后按 'B' 开始新批次`

#### **后续批次标定**

6. **移动标定板**
   - 将标定板移动到相机视野的其他位置（如右上角、下方等）
   - 确保每个批次覆盖不同的视野区域（以提高标定精度）

7. **开始新批次**
   - 按 **`B`** 开始新批次
   - 程序会检测新位置的黑色圆圈
   - 重复步骤3-5的操作

8. **重复操作**
   - 建议至少进行3个批次标定
   - 每个批次至少标定3个点（建议5个以上）
   - 总标定点数建议≥10个（最少需要3个点才能计算变换）

#### **最终保存**

9. **保存标定结果**
   - 所有批次标定完成后，按 **`C`** 保存最终结果
   - 程序会使用所有批次累积的数据计算三维刚体变换
   - 终端显示：
     - `总批次数: N`
     - `总标定点数: M`
     - `标定残差统计 (mm): RMSE_total=X.XX, max=X.XX, mean=X.XX`
     - 每个批次的RMSE统计
   - 结果保存到配置文件指定的YAML文件（默认：`yaml/manual_galvo_calibration.yaml`）

## 键盘操作说明

### 移动控制

| 按键 | 功能 | 说明 |
|------|------|------|
| **W** | 向上移动 | 振镜Y轴正方向移动 |
| **S** | 向下移动 | 振镜Y轴负方向移动 |
| **A** | 向左移动 | 振镜X轴负方向移动 |
| **D** | 向右移动 | 振镜X轴正方向移动 |
| **H** | 回原点 | 移动到振镜原点位置(0,0) |

### 步长控制

| 按键 | 功能 | 说明 |
|------|------|------|
| **Q** | 增加步长 | 增大移动步长（普通模式+100，精细模式+50） |
| **E** | 减小步长 | 减小移动步长（普通模式-100，精细模式-50） |
| **F** | 精细模式切换 | 切换普通模式/精细模式 |
|      |      | 普通模式：默认步长500 |
|      |      | 精细模式：默认步长100 |

### 标定流程控制

| 按键 | 功能 | 说明 |
|------|------|------|
| **B** | 开始标定/新批次 | 开始第一批次标定，或开始新的批次 |
| **M** | 完成当前批次 | 完成当前批次，准备开始新批次 |
| **R** | 记录当前点 | 记录当前目标点的标定数据 |
| **N** | 下一个目标 | 切换到下一个圆圈目标 |
| **P** | 上一个目标 | 切换到上一个圆圈目标 |
| **SPACE** | 自动对准 | 自动对准当前目标圆圈 |
| **C** | 保存最终结果 | 使用所有批次数据计算并保存变换 |
| **X** | 重置所有数据 | 清空所有批次数据，重新开始 |

### 其他功能

| 按键 | 功能 | 说明 |
|------|------|------|
| **L** | 激光开关 | 切换激光器开关状态 |
| **I** | 初始化到中心 | 将振镜移动到图像中心位置 |
| **K** | 停止流程 | 停止当前标定流程 |
| **O** | 测试四角映射 | 测试图像四角到振镜码值的映射 |
| **?** | 显示帮助 | 在终端显示所有按键说明 |
| **Ctrl+C** | 退出程序 | 安全退出标定程序 |

## 注意事项

### ⚠️ 标定前检查

1. **相机和振镜连接**
   - 确认相机正常工作，图像清晰
   - 确认振镜串口连接正确（检查 `/dev/ttyACM0`）
   - 确认激光器可以正常开关

2. **标定板质量**
   - 黑色圆圈要足够黑（避免反光）
   - 圆圈边缘清晰，无明显模糊
   - 圆圈大小适中（半径10-150像素）

3. **光照条件**
   - 避免强光直射标定板
   - 避免阴影遮挡
   - 确保深度信息有效

### ⚠️ 标定过程注意事项

1. **批次规划**
   - 每个批次应覆盖相机视野的不同区域
   - 建议至少3个批次，每个批次至少3个点
   - 总标定点数建议≥10个（最少需要3个）

2. **深度信息**
   - 确保每个标定点的深度值有效（程序会自动检查）
   - 如果某个点深度无效，程序会跳过并提示

3. **移动微调**
   - 使用普通模式（WASD）进行粗调
   - 切换到精细模式（F）进行细调
   - 调整步长（Q/E）以适应不同精度需求

4. **记录数据**
   - 每个点标定满意后再按R记录
   - 记录后程序会自动进入下一个目标
   - 可以使用N/P键返回之前的目标重新标定

5. **批次管理**
   - 完成一个批次后务必按M确认
   - 移动标定板后按B开始新批次
   - 不要在同一批次中混合不同位置的圆圈

### ⚠️ 结果验证

1. **残差检查**
   - RMSE_total应该尽量小（建议<5mm）
   - 各批次RMSE应相对均匀（差异不应过大）
   - 如果RMSE过大，考虑增加标定点或重新标定

2. **保存文件**
   - 确认YAML文件已正确保存
   - 检查文件路径和权限
   - 建议备份标定结果文件

## 故障排除

### 问题1：检测不到黑色圆圈

**可能原因**：
- 标定板不够黑（反射光）
- 圆圈太小或太大（超出10-150像素范围）
- 光照条件不佳
- 检测方法选择不当

**解决方法**：
- 检查标定板质量，确保黑色足够深
- 调整标定板距离，使圆圈大小合适
- 改善光照条件
- **尝试切换检测方法**：
  - 如果有反光问题，使用 `adaptive_threshold` 方法（默认）
  - 如果标准光照条件，可以尝试 `hsv` 方法
  - 修改方法：编辑 `scripts/galvo_calibrator_depth.py` 第162行
- 查看终端是否有检测相关的警告信息

### 问题2：圆圈ID频繁跳变

**可能原因**：
- 标定板移动过快
- 圆圈重叠或距离太近（<35像素）

**解决方法**：
- 保持标定板相对稳定
- 增加圆圈间距（≥35像素）
- 等待几帧让跟踪稳定后再操作

### 问题3：深度信息无效

**可能原因**：
- 距离太近或太远（超出深度相机范围）
- 标定板表面反光
- 深度相机未正确对齐

**解决方法**：
- 调整标定板距离（通常在0.3-3米范围内）
- 避免反光表面
- 检查相机对齐（`align_depth:=true`）
- 使用深度图查看器检查深度信息

### 问题4：振镜不响应

**可能原因**：
- 串口连接问题
- 串口权限问题
- 振镜硬件故障

**解决方法**：
- 检查串口设备路径（`ls /dev/ttyACM*`）
- 检查串口权限（`sudo chmod 666 /dev/ttyACM0`）
- 检查串口是否被其他程序占用
- 测试串口通信（可以使用test_teensy.py）

### 问题5：标定点不足

**错误信息**：
```
三维标定至少需要3个标定点，当前只有 N 个。
```

**解决方法**：
- 继续标定更多点（至少3个，建议10个以上）
- 可以添加更多批次
- 每个批次至少标定2个点

### 问题6：RMSE过大

**可能原因**：
- 标定点分布不均匀
- 标定点数量不足
- 深度测量误差
- 手动对准精度不够

**解决方法**：
- 增加标定点数量（建议≥15个）
- 确保标定点分布在视野的不同区域
- 使用精细模式提高对准精度
- 检查深度测量质量
- 重新标定

### 问题7：程序无法启动

**可能原因**：
- ROS环境未配置
- 相机驱动未安装
- 配置文件路径错误

**解决方法**：
- 确认ROS环境：`source ~/my_workspace/devel/setup.bash`
- 检查相机驱动：`rosnode list | grep realsense`
- 检查配置文件路径是否正确
- 查看终端错误信息

## 高级配置

### 修改串口参数

编辑 `calibration.launch` 文件：

```xml
<param name="serial_port" value="/dev/ttyACM0" />
<param name="serial_baudrate" value="115200" />
```

### 修改振镜索引

如果要标定其他振镜（多振镜系统）：

```xml
<param name="galvo_index" value="1" />  <!-- 0=第一个，1=第二个... -->
```

### 修改保存路径

```xml
<param name="calibration_result_file" 
       value="$(find laser_weeding)/yaml/manual_galvo_calibration.yaml" />
```

### 选择检测方法

程序支持两种黑色圆圈检测方法，可在代码中手动修改：

**方法1：自适应阈值（默认，推荐）**
- 编辑 `scripts/galvo_calibrator_depth.py`
- 找到第162行左右：`self.detection_method = 'adaptive_threshold'`
- 保持默认值即可

**方法2：HSV颜色空间**
- 编辑 `scripts/galvo_calibrator_depth.py`
- 找到第162行左右：`self.detection_method = 'adaptive_threshold'`
- 修改为：`self.detection_method = 'hsv'`

**两种方法对比**：

| 方法 | 优势 | 适用场景 |
|------|------|----------|
| `adaptive_threshold` | 抗反光，对光照变化鲁棒 | 有反光、光照变化大 |
| `hsv` | 简单直接，对纯黑色效果好 | 标准光照，无反光 |

### 禁用深度信息

如果不使用深度信息（仅2D标定）：

```xml
<param name="use_depth" value="false" />
```
